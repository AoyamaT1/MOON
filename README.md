## CUTMOON — 图片打孔器

一个单文件网页应用：上传图片 → 在图上打出各种形状的孔 → 孔里透出底板并带立体光影 → 打下来的碎片带着原图纹理掉在下方底板区。

不只是给画手用的。文手可以用它把诗句做成**撕纸拼贴**（开发中）。

### 特性

- **三种打孔方式**：预设（12 种构图样式自动排布）／点选（逐个点击）／轨迹（按住拖动画出笔迹，孔沿路径连续打出）
- **18 种孔形**：圆、方、三角、星、心、水滴、闪光、花、拼图、飞鸟……
- **立体效果**：凹陷倒角、纸厚断口、投影三种各自独立可开关，支持光源方向调节
- **手动微调**：孔和碎片都可以直接拖动；单击选中单个孔后可独立调大小／旋转；手动挪过的位置不会被重排冲掉
- **碎片歪斜**：碎片随机歪斜的幅度可调，也可以完全关掉让它们端正排列
- **打孔／碎片尺寸解耦**：碎片可以比孔大或小，做出层叠效果
- **完整撤销**：换构图、换形状、改任意滑块、重新打孔、删除孔——全都能撤销重做（`Ctrl+Z` / `Ctrl+Shift+Z`）
- **影调**：亮度、对比度、饱和度、色温、褪色、泛黄、模糊 + 颗粒、暗角、扫描线、半调网点。全部烘进预渲染阶段，运行时零开销
- **12 种底板纹理**：纯色、渐变、径向、纸纹、颗粒、亚麻、网点、斜纹、水彩、流纹、斑点、暗角——全部程序化生成，不加载任何图片资源
- **配置保存**：参数自动存在本机，支持命名预设与 JSON 导入导出
- **响应式**：手机竖屏上下布局，桌面／横屏自动变双栏

### 使用

直接打开 <https://aoyamat1.github.io/MOON/>，或把 `index.html` 下载到本地双击打开（**完全离线可用**，无任何外部依赖）。

- 拖拽图片到画布，或 `Ctrl+V` 粘贴
- `Ctrl+Z` 撤销 · `Ctrl+Shift+Z` 重做 · `R` 重新打孔 · `E` 导出
- 导出支持 1×／2×／3× PNG

### 说明

单文件、纯原生 JS + Canvas 2D，无构建步骤、无第三方库。全部状态保存在浏览器本地（localStorage），不上传任何数据——图片始终留在你自己的设备上。
